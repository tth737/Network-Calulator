# Sicherheit

## Unterstützte Versionen

Nur die jeweils neueste Version erhält Korrekturen.

## Sicherheitslücke melden

Bitte keine öffentlichen Issues für Sicherheitsprobleme. Nutze stattdessen die
private Meldung über den Reiter "Security" im Repository ("Report a
vulnerability"):

https://github.com/tth737/Network-Calulator/security/advisories/new

Bitte beschreibe:

- betroffene Version und Paket (Flatpak oder APK),
- Schritte zum Nachstellen,
- mögliche Auswirkungen.

Du erhältst eine Rückmeldung, sobald der Bericht geprüft wurde.
