# Mitwirken

Danke für das Interesse an Netzwerk-Speed.

## Fehler melden

Bitte ein Issue mit der Vorlage "Fehlerbericht" öffnen. Hilfreiche Angaben:

- Was hast du gemacht?
- Was hast du erwartet?
- Was ist stattdessen passiert?
- Betriebssystem und Paket (Flatpak oder APK) mit Version.

## Änderungen vorschlagen

1. Repository forken.
2. Branch anlegen, zum Beispiel fix/umrechnung-rundung.
3. Änderung umsetzen und lokal testen (flet run app.py).
4. Pull Request mit kurzer Beschreibung öffnen.

## Regeln

- Oberflächentexte nur in daten/texte.py und daten/wissen.py ändern.
- Keine Emojis in Code, Doku und Commit-Nachrichten.
- Commit-Nachrichten auf Deutsch, kurz und sachlich.
- Änderungen an der Rechenlogik bitte mit einem Beispiel begründen.
